# Veil 项目总文档

最后更新：2026-09-25 · 首版 0.1.0。

本文是项目持续维护的总入口。每次修改功能、目录、数据或运行方式时同步更新。开发前先阅读 `AGENTS.md`。

## 1. 产品与已确认范围

Veil 是模拟塔罗、星骰与神谕卡的 PWA。视觉为白色基底、沉稳灰紫、鼠尾草绿和少量香槟金，文字与按钮采用更清晰的深色层级，强调留白和牌的质感。

- 首页：三个主要入口，右上角历史记录与个人信息入口，下方知识库入口。
- 塔罗：完整 78 张经典韦特与 78 张古典马赛牌面；支持单副牌与完整混合的双副牌；右侧扇形牌堆；鼠标与触屏拨动、惯性；点击预选、取消或改选、确认翻面；正逆位；连续抽牌；重新洗牌；已抽牌可打开包含正逆位释义的单牌介绍；可一键复制主标题、全部牌位问题、牌名方向和对应牌义。
- 抽牌设置：依次呈现主问题、自绘日期与时间选择、可设置 1–12 个初始牌位的自由牌阵、单牌/双牌/三牌模板及逐牌位问题、牌组数量、两种牌面入口、五种浅色纯色桌布和星轨薄暮纹样桌布。自由牌阵抽满初始数量后可继续抽牌并自动扩展至最多 12 位；固定模板抽满后可确认切换为 12 位自由牌阵。
- 桌面：移动端优先，所有屏幕均为左侧摆牌、右侧扇形牌堆的统一桌面。手机左侧默认两列小牌，多张时独立纵向滚动；右侧牌堆固定靠边，新增牌保持可见。
- 历史：塔罗每轮一条，星骰每次投掷一条，按最近时间混合排列；可展开详情。塔罗当前轮次标记为进行中。
- 个人信息：展示本地访客身份、塔罗与星骰存档数量，集中说明本地存档边界，并提供带二次确认的全部本地记录清除入口。
- 星骰：三枚十二面骰的桌面界面、标题旁设置入口、与塔罗共用的自定义占卜时间、投掷动画、独立等概率结果、本地历史与刷新恢复；每条历史保留投掷当时的标题和占卜时间快照。
- 知识库：提供塔罗、星骰、神谕卡三个顶层栏目及稳定的递归子目录结构；当前栏目内容为待补充状态。
- 本地数据、刷新恢复、PWA 清单与离线缓存。
- 洗牌仅重排剩余牌，动画为收拢、三次交错切洗、重新展开；桌面牌保持原位。减少动态效果时简化为短淡入。

## 2. 长期不可偏离的约定

1. 用户提需求，先整理，得到确认再编码。
2. 唯一本地预览地址 **http://localhost:5106/**。不换端口、不自动回退到其他地址；只有用户明确要求才可修改。
3. 可维护性优先，不为了交付速度混放代码。每个功能、资源、数据各有明确位置。
4. 当前不接外部服务器、数据库、账号或统计，不发布到外网。
5. 新功能先确定边界和所属模块，再实现；不预先引入不必要的框架、服务或抽象。

## 3. 技术结构与理由

当前采用原生 ES Modules、语义化 HTML、CSS 与 Pointer Events，构建及预览使用 Node.js 内置模块，无运行时第三方依赖。功能通过独立视图、控制器、纯领域逻辑和存储适配器组成。此阶段无需引入服务器或框架；后续如状态与页面规模显著增长，可在保留领域层与仓储接口的前提下迁移 UI。

## 4. 抽牌规则

- 新轮次通过 Web Crypto `getRandomValues` + 拒绝采样取得无偏整数，再用 Fisher–Yates 对 78 张牌洗牌。
- 双副牌先建立 156 个唯一实体牌实例，再整体执行同一套 Fisher–Yates；两份同名牌概率相等且均可被抽到，不增加权重。
- 没有加权、保底、预设结果或按历史结果干预。
- 点击牌仅改变 UI 预选状态，不显示正面、不写入抽牌记录。
- 已选中的突出牌可以按住向左拖出：左移达到 `max(44px, 牌宽 × 0.6)` 后松手，相当于点击确认。达到阈值但未松手不会写入；右移、距离不足、触控取消、Escape、窗口失焦或拖动期间改变窗口尺寸均不确认。
- 确认时从选中的槽位取出牌，独立以 50% / 50% 决定正逆位；保存成功后才揭牌。
- 拖出确认与按钮确认共用同一用例。保存成功后，牌背浮层自动移到左侧最新牌位，落定后再翻面；保存失败会退回预选位置，不消费牌。减少动态效果偏好会跳过回弹及飞行动画。
- 一轮内不放回，已抽牌从牌堆移除。剩余不足两张时禁用洗牌。顶部“新牌阵”会以一次原子写入归档已有抽牌并创建空白牌阵；空桌不会生成空存档。
- 自由牌阵可设置 1–12 个初始牌位并逐一填写问题；抽满当前牌位后仍可继续选择，下一次确认抽牌会在同一次原子保存中追加新牌位并落牌，取消选择不扩展，最多 12 位。设置页随后显示实际扩展后的数量与全部牌位。单牌、双牌、三牌模板保持固定数量，抽满后可确认切换为 12 位自由牌阵，保留已抽牌及原牌位问题。
- 洗牌仅随机重排当前剩余牌，保留轮次 ID、已抽牌及正逆位、桌面位置和历史记录；不回收、不归档、不重开轮次。原有历史记录兼容保留。
- 方向键拨牌、Enter/Space 选择、Escape 取消，Home/End 可抵达首尾；减少动态效果偏好会关闭惯性和过渡。

### 抽牌页布局（2026-09-19 调整）

- 使用动态视口高度分配顶部导航、牌桌和底部操作空间，兼顾手机浏览器工具栏变化与屏幕安全区域。
- 手机竖屏始终左右排列，不切换为上下布局；左侧两列紧凑牌面，右侧扇形圆心置于屏幕外。窄屏和横屏分别调整牌面及扇形半径。
- 牌桌不使用独立面板、分区边框或装饰圆环；移除顶部介绍、空桌装饰文案、重复存储提示和抽牌页页脚。
- 已抽牌按顺序排列，保留中文牌名与正逆位，隐藏英文名及序号；多张时只滚动左侧，不带动右侧牌堆或底部操作区。
- 抽牌落定后可点击或用键盘打开单牌介绍；介绍统一使用正向牌图并同时展示正位与逆位含义，不因本次抽取方向改变内容。模态层压暗并锁定原桌面，关闭后恢复触发牌的焦点和原滚动位置；历史页牌面保持原有只读展示。
- 标题旁的复制按钮生成纯文本：默认或自定义主标题、全部牌位名称与问题、已经抽到的牌名和正逆位、牌面简介及本次方向对应牌义；尚未抽取的牌位明确标记。剪贴板不可用时显示失败提示，不修改牌阵或记录。
- 返回首页文字入口已移除，仍可通过全局 Veil 标志返回。新牌阵、洗牌、剩余牌数和设置位于顶部；底部完全留空。预选后取消与确认显示为桌面上层的独立悬浮操作条。
- 首页欢迎区域仅保留金色星形，移除英文小标题、主标题与副标题。
- 设置页覆盖当前桌面且独立滚动，顺序为主标题、占卜时间、牌位设计、牌组数量、牌面、桌布；占卜时间在设置正文中仅显示一张合并日期与时间的紧凑卡片，点击后以居中浮层打开项目内自绘月历、小时/分钟选择、“现在”与“完成”操作，不再向下撑开页面。浮层支持点击外部、完成按钮或 Escape 关闭，窄屏完整保持在视口内，默认采用创建轮次时的当前时间；塔罗与星骰共用同一组件和交互。牌阵模板使用带牌位示意图的独立预览框横向排列，窄屏可左右滑动并吸附。自由牌阵数量使用大尺寸减号/数字/加号计数器，触控区不小于 44px，边界按钮自动禁用。桌布可随时更新，主问题与牌位问题随当前轮次保存。更换牌组或已开始的牌阵结构会明确提示，确认后将有抽牌的旧轮次归档并重新准备牌堆。
- 牌面可选经典韦特与古典马赛；当前轮次及归档记录各自保存 `skinId`，抽牌桌、单牌介绍和历史详情使用该轮次对应牌面。古典马赛按语义牌 ID 对齐，正义 VIII 对应现有正义牌义，力量 XI 对应现有力量牌义，不改变抽牌集合或随机逻辑。
- 星轨薄暮桌布为项目内原创浅灰紫矢量纹样，以低透明度香槟金星轨、星芒和点状轨迹构成；桌布仅改变桌面表现，不改变或重开牌阵。
- 预选牌的按住拖动与整副牌的旋转分开处理：仅已选牌接管拖出，其余位置继续拨牌。拖动期间禁用底部操作，达到阈值提示“松手即可抽牌”；浮层独立于扇形裁剪区域，因此可跟随手指进入左侧桌面。
- 路由装配通过 `data-page` 标记当前页；沉浸式高度和精简外壳仅作用于抽牌页，首页及历史页保持原有布局。
- 全站共用顶部栏采用深紫黑底与浅色标志、文字和图标；顶部栏高度、入口位置和交互保持不变，下缘使用透明渐变自然过渡到各页面内容背景。

## 5. 本地数据与失败处理

存储键：`veil.readings.v1`。UI 预选和手势位置不保存。

```text
Store
  version: 4
  revision: 非负整数
  current: Session | null
  history: Session[]（新记录在前）

Session
  id: UUID
  readingAt: 用户指定的占卜时间
  startedAt / updatedAt: 技术创建与更新时间
  config: deckCount / skinId / clothId / question / spread
  deck: InstanceId[]（剩余实体牌，双副牌使用 copy 后缀）
  draws: Draw[]（按抽取顺序）

Draw
  instanceId: 实体牌唯一 ID
  cardId: 稳定牌 ID
  positionId: 牌位 ID 或 null
  reversed: boolean
  drawnAt: ISO 时间
```

每轮剩余牌与已抽牌必须恰好构成 78 或 156 张唯一合法实体牌；时间、版本、轮次 ID、配置和数据字段在读取及写入时校验。当前轮与历史共同写入一个 localStorage 值，避免牌被移除但记录没有落盘。旧版 version 1 单副牌记录、version 2 的旧自由/自定义牌阵以及 version 3 记录读取时无损迁移为 version 4；旧自定义牌阵保留数量和问题并改为自由牌阵，旧无限自由牌阵迁移为 12 位，旧轮次以 `startedAt` 补充 `readingAt`。原始值在下一次有效写入前不会被静默覆盖。

星骰使用独立键 `veil.dice.v1`，内部格式为 version 3：保存标题草稿 `draftTitle` 和仅用于下一次投掷的 `draftReadingAt`，每条记录包含 `id / rolledAt / readingAt / title / values`。`rolledAt` 是实际投掷技术时间，`readingAt` 是用户指定的占卜时间；历史按后者排序和展示。投掷时标题、占卜时间与三个骰子结果在一次写入中保存，成功后时间草稿清空并在下次设置时恢复当前时间，标题继续保留。旧版 version 1、2 记录在内存中补齐标题或占卜时间，写入前不覆盖原始值。

浏览器支持 Web Locks 时，各标签页提交串行执行；另有版本和牌槽校验，防止陈旧页面覆盖新数据。`storage` 事件同步其他标签页；只读打开既有轮次不写入数据，避免循环更新。无 Web Locks 的浏览器仅保留乐观版本冲突检测。

空间不足、权限关闭、数据损坏或未知版本会提示失败，不静默清空、不覆盖原始数据。保存失败不展示成功结果。刷新恢复完整牌堆与当前桌面。

当前数据仅属于本设备、同一浏览器、同一源；清除站点数据会删除记录。尚未提供云备份、导入导出或账户同步。该说明和“清空全部记录”入口集中展示在个人信息页，其他功能页不重复占用操作空间。主动清除会同时删除塔罗当前轮次、塔罗历史、星骰记录与标题草稿；两类存储任一删除失败时尽力恢复原值，成功后只创建一个新的空白塔罗轮次。

## 6. PWA 与离线

- 清单包含名称、固定启动路径、独立窗口模式及 192/512 图标。
- 构建生成基于资源内容的缓存版本；安装时预缓存首页、全部模块、样式、图形和两套共 156 张牌面；当前构建包含 236 个本地资源。
- 只有资源全部缓存成功才激活；失败不替换当前可用离线版本。
- 在线优先读网络，保证本地开发刷新可见；断网读取完整缓存版本。
- `npm run dev` 先构建缓存，再固定监听 localhost:5106；开发服务器不做 HMR，修改后手动刷新。更新离线内容需重新 build。
- 首次打开必须成功完成缓存准备，然后才能完全离线。安装到主屏幕由支持的浏览器提供，实际入口因平台而异。
- 桌面浏览器离线与触屏模拟可验证；iOS/Android 真机安装体验需后续真机验收。
