# Veil · 未明

移动端优先的塔罗与星骰 PWA。白色桌面、沉稳灰紫与暖金细节，所有记录保存在当前浏览器中。

## 功能

- **塔罗**：韦特与古典马赛牌面，单副/双副牌，扇形拨牌、拖出抽牌、正逆位、剩余牌洗牌动画、牌阵设置和单牌释义。
- **星骰**：星体、星座、宫位三枚骰子，投掷动画、独立等概率随机结果和自定义占卜时间。
- **本地记录**：塔罗与星骰历史、刷新恢复，以及个人信息页的记录管理。
- **知识库**：分类与子目录框架；内容待补充。神谕卡入口暂为占位。
- **离线**：首次完整缓存后可离线使用。清除网站数据会删除本地记录。

不接入账号、外部数据库或统计服务。上传代码不会上传浏览器里的占卜记录。

## 开始使用

需要 **Node.js 22 或更高版本**。项目使用原生 ES Modules 和 Node.js 内置模块，没有第三方运行或构建依赖，无需执行 `npm install`。

```sh
npm run dev
```

唯一预览地址：**http://localhost:5106/**。端口占用时退出，不会自动更换地址。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 构建离线缓存并启动开发预览 |
| `npm test` | 领域规则、随机和存储测试 |
| `npm run check` | JavaScript 语法、156 张牌面与 PWA 图标检查 |
| `npm run build` | 执行检查，生成 `dist/` 和离线缓存版本 |
| `npm run preview` | 在同一固定地址预览 `dist/`，需先构建并停止开发服务器 |

开发服务器直接读取源码，修改后刷新即可查看；发布构建或验证离线行为前重新执行 `npm run build`。生成文件不提交 Git。

## 目录与开发

```text
src/app/              路由装配与全局样式入口
src/features/         按业务划分的页面、组件、领域规则和数据
src/shared/           公共 UI、工具和设计令牌
src/infrastructure/   存储、PWA 与浏览器能力适配
public/assets/        本地牌面、图标、骰子和桌布
scripts/              无第三方依赖的检查、构建和本地服务器
tests/                Node.js 内置测试框架用例
docs/                 项目总文档、资源与 GitHub 提交说明
.github/workflows/    推送及 PR 的自动测试与构建
```

先整理需求并确认，再修改代码；按功能分离规则、交互和存储，每次修改同步项目总文档。随机使用 Web Crypto，整数拒绝采样，洗牌采用 Fisher–Yates。洗牌只处理剩余牌。

## GitHub 与资源许可

GitHub Actions 对推送和 PR 执行 Node.js 22、24 的测试与构建；不部署网站。当前路径按站点根目录设计，不能直接把构建放到 GitHub Pages 的仓库子路径使用。

牌面等第三方资源的来源与许可保留在资源目录，并在资源文档中汇总。项目自身代码尚未指定开源许可证；第三方资源许可不代表整个项目采用同一许可。
