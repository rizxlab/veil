# 古典马赛牌面来源

- 牌组：Woodcut Tarot，完整 78 张彩色 Tarot de Marseille。
- 原作：Jean Noblet tarot，巴黎，约 1650 年；缺失的权杖六至十取自同时期 Jacques Viéville tarot。
- 数字化来源：法国国家图书馆 Gallica 馆藏扫描。
- 矢量重制：SONDLecT，https://github.com/SONDLecT/woodcut-tarot
- 许可：CC0 1.0 Universal；原作版权已于数百年前到期，重制贡献释入公有领域。
- 本项目处理：将彩色 SVG 渲染并压缩为 350 × 602 像素 JPEG；文件名按 Veil 的语义牌 ID 对齐。马赛体系的正义 VIII 对应 `major-11`，力量 XI 对应 `major-08`。
